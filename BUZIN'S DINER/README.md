# BUZIN'S DINER

A responsive restaurant landing page built with HTML, CSS, and JavaScript.

## Run locally

From this directory, run:

```powershell
python -m http.server 8000
```

Then open <http://localhost:8000>.

This is a static site and can be imported into Vercel without a build step. It uses the included `profile.jpg` and loads fonts, icons, Tailwind CSS, and some food imagery from external CDNs.
